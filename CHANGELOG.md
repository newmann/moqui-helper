# Changelog

## 0.1.0

XML assistance for Moqui Framework 3. Structural completion and diagnostics come from the schemas shipped with this extension and Red Hat XML. The language service indexes entities, services, screens, and the names inside those files.

- Completion, go to definition, hover, find references, rename, reference counts, and unresolved diagnostics for those names
- Explorer badges, form folding, and an outline for Moqui XML
- Dynamic tags in `entity-facade-xml` and `seed-data`
- Fixed-value completion for entity packages, parameter types, and common date and number formats
